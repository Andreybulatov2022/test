# Локальный ИИ-репетитор: полная инструкция

Компьютер: HyperPC, RTX 4070 12 ГБ, 32 ГБ ОЗУ, Windows 11.
Всё работает на этом же ПК, без интернета и без отправки данных наружу (интернет нужен только для скачивания).

Что получится: ребёнок нажимает ярлык «Начать занятие», в браузере открывается чат-репетитор, который **не даёт готовых ответов, а наводит вопросами**. Закончил — нажал «Закончить занятие», и всё выключается.

> Ссылки ведут на главные страницы официальных сайтов. Интерфейсы иногда меняются, поэтому названия кнопок могут слегка отличаться.

---

## Шаг 0. Что нужно скачать

| Что | Зачем | Ссылка |
|---|---|---|
| Ollama | запускает ИИ-модели | https://ollama.com/download |
| Docker Desktop | запускает веб-интерфейс чата | https://www.docker.com/products/docker-desktop/ |
| Open WebUI | сам интерфейс чата (скачается через Docker) | документация: https://docs.openwebui.com |

Свободного места нужно около 25 ГБ (модели ~8 ГБ + Docker).

---

## Шаг 1. Установить Ollama

1. Скачайте установщик по ссылке выше и запустите его.
2. Откройте **PowerShell** (Пуск → напишите `PowerShell`).
3. Скачайте модели:

```powershell
ollama pull gemma3:12b
ollama pull bge-m3
```

- `gemma3:12b` — основная модель-репетитор (~8 ГБ). Хорошо пишет по-русски и понимает **фото** тетради и учебника.
- `bge-m3` — маленькая модель для поиска по учебникам (понимает русский).

Проверка: `ollama run gemma3:12b`, напишите «Привет». Выход: `/bye`.

> Модель целиком помещается в 12 ГБ видеопамяти, поэтому отвечает быстро.
> Дополнительно для сложной математики можно поставить `ollama pull qwen3:14b`. Но у неё включён «режим размышления», где она может показать ребёнку готовое решение. Для репетитора безопаснее `gemma3:12b`.

---

## Шаг 2. Создать модель «Репетитор»

1. Скопируйте файл `Modelfile` из этой папки (`tutor-kit`) в `C:\Tutor\`.
2. Возраст и класс (14 лет, 8 класс) уже вписаны. Если нужно изменить, откройте файл в Блокноте и поправьте строку с возрастом.
3. В PowerShell:

```powershell
cd C:\Tutor
ollama create tutor -f Modelfile
```

Появилась модель `tutor`. Именно её будет использовать ребёнок. Промпт с правилами «не давать ответ» уже внутри.

---

## Шаг 3. Установить Docker Desktop и запустить Open WebUI

1. Установите Docker Desktop по ссылке выше. Если попросит, включите WSL 2 и перезагрузите ПК.
2. Откройте Docker Desktop, дождитесь, пока он запустится.
3. В PowerShell выполните (одной строкой):

```powershell
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -e OLLAMA_BASE_URL=http://host.docker.internal:11434 -v open-webui:/app/backend/data --name open-webui ghcr.io/open-webui/open-webui:main
```

Без `--restart always`, чтобы чат сам не запускался вместе с Windows.

4. Откройте в браузере http://localhost:3000
5. **Первая регистрация становится администратором.** Зарегистрируйтесь сами (родитель): имя, почта (любая), пароль.

## Шаг 4. Настроить интерфейс (под родителем)

### 4.1. Включить поиск по учебникам на русском
Админ-панель (значок профиля → **Admin Panel**) → **Settings** → **Documents**:
- **Embedding Model Engine** → `Ollama`
- **Embedding Model** → `bge-m3`
- Нажмите **Save**.

### 4.2. Запретить саморегистрацию
**Admin Panel → Settings → General** → выключите **Enable New Sign Ups**. Сохраните.

### 4.3. Создать аккаунт ребёнка
**Admin Panel → Users → «+»** → имя ребёнка, почта, пароль, роль **User**.

### 4.4. Показать ребёнку только репетитора
1. **Workspace → Models** → найдите `tutor` → значок настроек → **Visibility/Access** → поставьте доступ для пользователей (Public/All Users).
2. Остальные модели (`gemma3:12b` и другие) сделайте приватными: **Admin Panel → Settings → Models** → у каждой выключите доступ для пользователей.

Войдите под аккаунтом ребёнка и проверьте: в выпадающем списке должен остаться только `tutor`.

## Шаг 5. Загрузить учебники

### Где взять
- Электронные формы учебников (ЭФУ): издательство «Просвещение» (https://lecta.ru), «Российский учебник» (https://rosuchebnik.ru), «Учебники» ЭФУ (https://uchebnik.mos.ru для московских школ).
- Бесплатные уроки по ФГОС: Российская электронная школа https://resh.edu.ru
- У школьной библиотеки или классного руководителя можно спросить официальные электронные версии.
- Отсканируйте или сфотографируйте свой бумажный учебник и соберите в PDF (потребуется распознавание текста, см. ниже).

> Загружайте только материалы, которые вы вправе использовать для личных целей (ваши учебники, школьные ЭФУ, свободные материалы).

### Что подойдёт
- **PDF с текстом** (можно выделить мышкой текст) — идеально.
- **Сканы-картинки в PDF** — нужно сначала распознать текст (OCR), например в Adobe Acrobat, ABBYY FineReader или бесплатно через https://www.ocr2edit.com. Без текста модель их не прочитает.
- Файлы лучше делить по предметам и классам, один учебник на файл.

### Как загрузить
1. Под родителем: **Workspace → Knowledge → «+»** (Create).
2. Название: `Математика 5 класс` (отдельная база на предмет).
3. Нажмите «+» → **Upload files** и выберите PDF. Дождитесь окончания обработки.
4. Повторите для других предметов.
5. Подключите базу к репетитору: **Workspace → Models → tutor → Edit → Knowledge → Select Knowledge** → выберите нужные базы → **Save**.

Теперь репетитор опирается на ваши учебники. Если хотите, чтобы он подробнее цитировал определения, добавьте в его системный промпт строку:
«Опирайся на материалы учебника из базы знаний, используй те же термины, что в учебнике».

## Шаг 6. Ярлыки «Начать» и «Закончить»

1. Создайте папку `C:\Tutor\`.
2. Скопируйте туда `Start-Tutor.bat` и `Stop-Tutor.bat` из этой папки.
3. Правой кнопкой по каждому → **Отправить → Рабочий стол (создать ярлык)**. Переименуйте ярлыки в «Начать занятие» и «Закончить занятие».
4. Отключите автозапуск:
   - Диспетчер задач → **Автозагрузка** → отключите **Ollama**.
   - Docker Desktop → **Settings → General** → снимите «Start Docker Desktop when you sign in».

Как работает:
- **Начать** → запускает Ollama и Docker, включает чат и открывает браузер (занимает ~1 минуту).
- Если ребёнок забыл выключить, модель сама выгрузится из видеокарты через 10 минут без запросов.
- **Закончить** → останавливает чат, Ollama и Docker, освобождает память.

В адресной строке браузера заходить нужно на http://localhost:3000 (скрипт откроет сам).

---

## Шаг 7. Как пользоваться ребёнку

1. Нажать «Начать занятие», подождать, пока откроется чат.
2. Войти под своим логином.
3. Выбрать модель `tutor` (она единственная).
4. Написать задание или прикрепить **фото** страницы (значок скрепки).
5. Репетитор будет задавать наводящие вопросы. Отвечать нужно по шагам.
6. Закончил → «Закончить занятие».

Можно включить голосовой ввод: **Settings → Audio** (микрофон должен быть разрешён в браузере).

---

## Шаг 8. Репетиторы по предметам (8 класс)

Готовые промпты для всех 12 предметов (алгебра, геометрия, вероятность и статистика, информатика, физика, химия, биология, русский язык, литература, история, английский, география) лежат в файле `PROMPTY-PO-PREDMETAM.md`.

Для каждого предмета:
1. **Workspace → Models → «+»**, имя предмета, базовая модель `tutor`.
2. Вставьте блок из файла в **System Prompt**.
3. В **Knowledge** подключите учебник по этому предмету (шаг 5).
4. Сохраните и дайте доступ ребёнку.

Ребёнок выбирает нужный предмет в списке моделей.

## Решение проблем

| Проблема | Что делать |
|---|---|
| Страница http://localhost:3000 не открывается | Подождите ещё минуту: Docker запускается долго. Проверьте, что в Docker Desktop контейнер `open-webui` запущен |
| В списке нет моделей | Убедитесь, что запущен Ollama (`ollama list` в PowerShell). Проверьте, что при создании контейнера был параметр `OLLAMA_BASE_URL` |
| Репетитор слишком быстро даёт ответ | Допишите в промпт строгие фразы вроде «Если ребёнок просит ответ, откажись три раза подряд, дай только подсказку». Протестируйте сами |
| Ответы медленные | Закройте игры и тяжёлые программы, они занимают видеопамять. Попробуйте `ollama pull qwen2.5:7b` и создайте на ней второго репетитора |
| Не находит в учебнике | Проверьте, что в PDF есть текст (а не только картинки), и что учебник подключён к модели `tutor` |
| Модель ошибается в задаче | Это возможно у любых локальных моделей. Для сложных заданий сверяйтесь с учебником и периодически просматривайте историю чатов под родителем |

## Обновление

- Модель: `ollama pull gemma3:12b`, затем снова `ollama create tutor -f Modelfile`.
- Open WebUI: `docker pull ghcr.io/open-webui/open-webui:main`, затем остановить, удалить и создать контейнер той же командой из шага 3 (данные сохранятся в томе `open-webui`):
  `docker stop open-webui` → `docker rm open-webui` → команда из шага 3.
