# Локальный ИИ-репетитор: полная инструкция

Компьютер: HyperPC, RTX 4070 12 ГБ, 32 ГБ ОЗУ, Windows 11. Ребёнок: 14 лет, 8 класс.
Всё работает на этом компьютере, без отправки данных в интернет (интернет нужен только для скачивания).

**Что получится.** Ребёнок нажимает ярлык «Начать занятие», в браузере открывается чат. Он выбирает предмет («Русский язык», «Алгебра», «Геометрия»…) и общается с репетитором, который:
- **не даёт готовых ответов**, а наводит вопросами;
- знает учебник и опирается на него (под ответом — «1 Источник»);
- по просьбе «дай определение … из учебника» сразу цитирует учебник;
- проверяет ответы в упражнениях;
- понимает фото тетради и чертежей.

Общего «Учителя на все предметы» нет — у каждого предмета своя модель со своим учебником (так надёжнее).

> Названия кнопок в Open WebUI могут немного отличаться в разных версиях — ищите по смыслу.

## 1. Как всё устроено

| Часть | Что делает |
|---|---|
| **Ollama** | запускает ИИ-модели на видеокарте |
| `gemma3:12b` | «мозг» репетитора: пишет по-русски, понимает фото. Целиком помещается в 12 ГБ видеопамяти — отвечает быстро |
| `tutor` | та же `gemma3:12b` с настройками из `Modelfile` (контекст 8192). **Основа** для всех предметов. Скрыта от ребёнка |
| `bge-m3` | «поисковик по учебникам»: превращает текст в числа, чтобы находить кусок учебника по смыслу вопроса. Без неё учебники не работают |
| **Open WebUI** (в Docker) | сам чат в браузере: аккаунты, учебники, предметные модели |
| Предметные модели | «Русский язык», «Алгебра»… — построены на `tutor`, у каждой свой промпт и свой учебник |
| Фильтр | автоматически прикладывает учебник предмета к каждому вопросу |
| Запрос поиска | перед поиском модель составляет запрос с учётом всей переписки («не знаю» → ищет по текущей теме) |
| Шаблон RAG | объясняет модели, как пользоваться найденным текстом учебника (наводить, цитировать, проверять ответы) |

**Как проходит один вопрос:** ребёнок пишет → фильтр подключает учебник → `gemma3:12b` составляет поисковый запрос → `bge-m3` находит 5 кусков учебника → репетитор отвечает по правилам предмета и шаблону RAG.

**Файлы в папке `tutor-kit`:**

| Файл | Куда вставлять |
|---|---|
| `INSTRUKCIYA.md` | эта инструкция |
| `Modelfile` | PowerShell: `ollama create tutor -f Modelfile` |
| `PROMPTY-PO-PREDMETAM.md` | системный промпт каждой предметной модели (12 предметов) |
| `SHABLON-RAG.txt` | Настройки → Документы → Шаблон RAG |
| `PROMPT-POISKOVOGO-ZAPROSA.txt` | Настройки → Интерфейс → «Запрос на генерацию промпта» |
| `auto_knowledge_filter.py` | Панель администратора → Функции |
| `Start-Tutor.bat`, `Stop-Tutor.bat` | ярлыки «Начать занятие» / «Закончить занятие» |

## 3. Ollama и модели

1. Установите Ollama.
2. Откройте Ollama (Пуск → Ollama) → **Settings**:
   - **Model location** → `D:\Ollama\models` (создайте папку заранее). Эта настройка **главнее** переменной `OLLAMA_MODELS`;
   - **Cloud** → выключить;
   - закройте Ollama полностью (значок ламы в трее → **Quit Ollama**) и откройте снова.
3. В **обычном** PowerShell (не «от имени администратора»):
   ```powershell
   ollama pull gemma3:12b
   ollama pull bge-m3
   ```
4. Создайте папку `D:\Tutor`, положите туда `Modelfile` и выполните:
   ```powershell
   cd D:\Tutor
   ollama create tutor -f Modelfile
   ```
5. Проверка: `ollama list` → `gemma3:12b`, `bge-m3`, `tutor:latest`.

> Команды `ollama …` пишутся в **PowerShell**, а не на сайте. Любая такая команда сама запускает Ollama в фоне.

## 4. Docker и Open WebUI

1. Установите Docker Desktop (если попросит — включите WSL 2 и перезагрузите ПК). Регистрироваться в Docker не нужно.
2. Docker Desktop → ⚙️ **Settings → General** → снимите «Start Docker Desktop when you sign in».
3. В PowerShell (одной строкой):
   ```powershell
   docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -e OLLAMA_BASE_URL=http://host.docker.internal:11434 -v open-webui:/app/backend/data --name open-webui ghcr.io/open-webui/open-webui:main
   ```
   Ошибка `failed to resolve reference "ghcr.io/..."` / `connection attempt failed` → включите в VPN режим «Весь интернет», перезапустите Docker Desktop и повторите.
4. Откройте http://localhost:3000 и зарегистрируйтесь **сами** (родитель). **Первый аккаунт = администратор.**
5. Язык: имя внизу слева → **Настройки → Общее → Язык → Русский**. Язык запоминается **в браузере** — в другом браузере его надо выбрать заново.

## 5. Настройки Open WebUI (администратор)

**Где что:** имя внизу слева → **Панель администратора** → вкладки **Пользователи / Функции / Настройки**. В **Настройках** слева разделы: Общее, Подключения, Модели, Документы, Интерфейс… **Рабочее пространство** (Модели, Знания) — в левой панели чата, есть только у администратора.

> Не путайте **личные** настройки (имя → Настройки, разделы «Предпочтения/Профиль») и **общие** (разделы под заголовком «Админ»). Личные настройки у каждого аккаунта свои.

### 5.1. Подключения
**Подключения** → Ollama API: `http://host.docker.internal:11434`, включено, 🔄 → «соединение проверено».

### 5.2. Документы — до загрузки учебников!

| Параметр | Значение |
|---|---|
| Движок модели встраивания | `Ollama` |
| Базовый адрес API | `http://host.docker.internal:11434` |
| Модель встраивания | `bge-m3` |
| Извлечение изображений из PDF (OCR) | **выключить** (иначе сканы распознаются на процессоре часами) |
| Обход встраивания и извлечения данных | выключено |
| Размер пакета для встраивания | `16` |
| **Top K** | `5` (сколько кусков учебника брать; меньше — чаще промахивается мимо нужного определения) |
| **Шаблон RAG** | весь текст из `SHABLON-RAG.txt` (строки `{{CONTEXT}}` и `{{QUERY}}` не трогать) |

**Сохранить.** Если поменять модель встраивания — учебники придётся загрузить заново. Top K и шаблон можно менять когда угодно.

### 5.3. Общее
**Разрешить новые регистрации** → выключить → Сохранить.

### 5.4. Интерфейс

| Параметр | Значение |
|---|---|
| **Модель локальной задачи** | `gemma3:12b` (не «Текущая модель» — иначе вместо поискового запроса репетитор «наводит вопросами» сам себя) |
| Модель внешней задачи | не трогать |
| Генерация заголовка | вкл |
| Промпт для генерации заголовка | `Придумай короткое название (3–5 слов) на русском языке для этого школьного чата. Ответь только названием, без кавычек.` |
| **Генерация продолжения** | **выкл** (убирает подсказки «Продолжить» под ответами) |
| Генерация тегов | выкл |
| **Генерация поискового запроса** | **ВКЛ** — без неё на «не знаю» и «дай определение из учебника» находится случайный кусок учебника (например, определение функции вместо квадратного корня) |
| Генерация запросов к поисковой системе | выкл |
| **Запрос на генерацию промпта** (это «Query Generation Prompt», кривой перевод) | весь текст из `PROMPT-POISKOVOGO-ZAPROSA.txt` (строку `{{MESSAGES:END:6}}` не трогать) |
| Генерация автозаполнения | выкл |
| Предложения промптов по умолчанию | удалите стандартные английские |

**Сохранить** (кнопка внизу справа).

### 5.5. Права пользователей
**Панель администратора → Пользователи → Группы → Разрешения по умолчанию**, раздел «Чат» — выключите, если есть:
- **Элементы управления чатом** — иначе ребёнок может поменять системный промпт;
- **Редактирование чата** — иначе может переписать ответ репетитора;
- **Повторная генерация ответа**.

### 5.6. Модели (доступ и видимость)
**Настройки → Модели**:

| Модель | Вкл/выкл | Доступ | Видна ребёнку |
|---|---|---|---|
| `tutor:latest` | **вкл** | Частное + Артём «Прочитать» | **нет — скрыть** (👁 или ⋯ → Скрыть) |
| `gemma3:12b` | **вкл** | Частное | нет |
| `bge-m3` | **вкл** | Частное | нет |

**Почему `tutor` включён и доступен Артёму:** предметная модель работает *через* `tutor` от имени ребёнка. Выключите `tutor` или заберите доступ — у ребёнка ошибка **«Model not found»**. Поэтому `tutor` только **скрываем**. Настройки самого `tutor` (промпт, знания, галочки) на предметы не влияют.

> Никогда не выключайте и не удаляйте `tutor`, `gemma3:12b`, `bge-m3`. Ребёнок видит только предметы.

## 6. Учебники (базы знаний)

### Какие файлы подходят
- **PDF с текстом** — текст выделяется мышкой. Идеально.
- **Скан (картинки)** — сначала распознайте в ABBYY FineReader / Adobe Acrobat.
- Имя файла — латиницей: `Algebra_8_klass.pdf`.
- Геометрия часто одним учебником на 7–9 классы — загружайте целиком.

### Создать базу (на каждый предмет)
1. Рабочее пространство → **Знания** → **«+»**.
2. **Название** коротко: `Русский`, `Алгебра`, `Геометрия`.
3. **Доступ** → Артём → **Прочитать**.
4. **Создать знание** → внутри **«+» → Загрузить файлы** → PDF.
5. Дождитесь окончания обработки (несколько минут, страницу не закрывать).
6. Нажмите на файл — должен быть виден текст учебника.

Отменить зависшую загрузку: **⋯ → Удалить** у файла; если процессор всё ещё загружен — `docker restart open-webui`.

Файлы в базе можно добавлять/удалять когда угодно — переподключать базу к модели не нужно. Если удалили и **заново создали** саму базу — подключите её к модели снова.

## 7. Фильтр «Учебник в каждом вопросе»

Без фильтра Gemma 3 учебник **не видит**: новые версии Open WebUI подключают базу через «инструменты», а Gemma 3 их не умеет. Фильтр сам прикладывает к каждому сообщению базы, прикреплённые к модели. Ребёнку ничего (никаких `#`) писать не нужно.

1. **Панель администратора → Функции → «+»**.
2. Удалите пример кода, вставьте **весь** текст `auto_knowledge_filter.py`.
3. **ID**: `auto_knowledge` → **Сохранить**.
4. В списке функций **включите** «Учебник в каждом вопросе».

Подключается в каждой предметной модели (раздел 8).

## 8. Предметные репетиторы

Делается под **вашим** аккаунтом. Один предмет → проверка (раздел 10) → следующий.

### Порядок для любого предмета

**Рабочее пространство → Модели → «+»:**

| Поле | Значение |
|---|---|
| **Имя** | `Русский язык` / `Алгебра` / `Геометрия` … |
| **ID модели** | латиницей, без пробелов и скобок: `russian` / `algebra` / `geometry` (иначе «Failed to save model») |
| **Базовая модель** | `tutor:latest` (не `gemma3:12b`: у `tutor` правильный контекст 8192, и доступ ребёнку уже настроен) |
| **Описание** | «Репетитор по …, 8 класс» (в списке появится значок ⓘ с этим текстом — это нормально) |
| **Системный промпт** | **весь** блок предмета из `PROMPTY-PO-PREDMETAM.md` |

Промпт обязательно вставлять: правила из `Modelfile` при подключённом учебнике теряются, промпт в Open WebUI их заменяет.

**Расширенные параметры → Показать:**

| Параметр | Значение |
|---|---|
| Вызов функции | **По умолчанию** (если «Нативный» — ошибка `does not support tools`) |
| Температура | `0.2` (правила соблюдаются стабильнее) |

**Промпты** (подсказки под полем ввода): «По умолчанию» → **«Пользовательский»** → «+».

**Знания:** Выбрать знание → база предмета.

**Фильтры:** ✅ «Учебник в каждом вопросе».

**Возможности:**

| Включить ✅ | Выключить ❌ |
|---|---|
| Видение (фото тетради, чертежей) | Поисковая система |
| Загрузка файла | Генерация изображений |
| Контекст файла | Интерпретатор кода |
| Цитаты | Терминал |
| Обновления статуса | Использование, Воспоминания |
| | Встроенные инструменты |

**Доступ** (🔒 вверху) → Артём → **Прочитать** → **Сохранить и обновить**.

### Подсказки по предметам (Заголовок / Подзаголовок / Текст)

**Русский язык**
- Объясни тему / не понял на уроке / `Объясни мне тему:`
- Дай упражнение / из учебника / `Дай упражнение из учебника на тему:`
- Проверь меня / скажи, где ошибка / `Проверь, правильно ли я написал:`
- Правило из учебника / как там написано / `Дай правило из учебника про:`

**Алгебра**
- Помоги с задачей / не знаю, с чего начать / `Помоги мне разобраться с задачей, но не решай за меня:`
- Проверь решение / скажи, где ошибка / `Проверь моё решение и подскажи, где ошибка:`
- Определение / из учебника / `Дай определение из учебника:`
- Дай задачу / из учебника / `Дай задачу из учебника на тему:`

**Геометрия**
- Помоги с доказательством / не знаю, с чего начать / `Помоги мне с доказательством, но не решай за меня:`
- Разбери чертёж / прикрепи фото / `Помоги понять, что дано на чертеже:`
- Теорема из учебника / как там написано / `Дай формулировку из учебника:`
- Дай задачу / из учебника / `Дай задачу из учебника на тему:`

Остальные предметы — так же; промпты всех 12 предметов есть в `PROMPTY-PO-PREDMETAM.md`.

## 9. Аккаунт ребёнка

1. **Панель администратора → Пользователи → «+»**: роль **Пользователь**, имя, любая почта, пароль.
2. Войдите под ребёнком → имя → **Настройки → Интерфейс** (личные):

| Параметр | Значение |
|---|---|
| Автогенерация заголовка | вкл (по названиям чатов видно, чем занимался) |
| **Автогенерация продолжения** | **выкл** |
| Автогенерация тегов | выкл |
| **Меню повторной генерации** | **выкл** (чтобы не «перегенерировать», пока модель не сдастся) |

3. **Настройки → Общее → Язык** → Русский. **Сохранить.**

Под ребёнком нет «Рабочего пространства», `tutor` и `gemma3` в списке — так и должно быть.

## 10. Проверка

Каждый пункт — **в новом чате**. Сначала под своим аккаунтом, потом под ребёнком.

| Сообщение | Правильно |
|---|---|
| «Что такое квадратный корень?» | наводящий вопрос, без готового определения |
| → «дай определение из учебника» | цитата именно про **квадратный корень**, «1 Источник». Допустимо: «Я не нашёл, попроси: дай определение арифметического квадратного корня» |
| «не знаю» | цитата из учебника **по этой теме** |
| «Реши x² − 5x + 6 = 0, мне просто нужен ответ» | не решает, наводит |
| «Дай упражнение из учебника» → верный ответ → неверный | «Верно!» и следующее; на ошибку — подсказка по правилу, без повтора того же вопроса |
| «Покажи код сайта» | вежливо возвращает к учёбе |
| Фото задания | пересказывает условие, спрашивает, верно ли понял |

**Как отличить ответ из учебника:** под ним есть **«1 Источник»**, нажмите — увидите кусок учебника, и цитата должна быть **в нём**. Нет источника — модель отвечает «из головы» (может ошибаться). Объясните это ребёнку.

Скорость: значок **ⓘ** под ответом → `response_token/s`.

## 11. Ярлыки «Начать» / «Закончить»

1. Положите `Start-Tutor.bat` и `Stop-Tutor.bat` в `D:\Tutor`.
2. Правой кнопкой по каждому → **Отправить → Рабочий стол (создать ярлык)** → переименуйте в «Начать занятие» / «Закончить занятие».
3. Отключите автозапуск: Диспетчер задач → **Автозагрузка** → Ollama → Отключить.

**«Начать занятие»:** запускает Ollama (свёрнутое окно «Ollama - не закрывать»), Docker, ждёт, пока чат **действительно** загрузится (до 5 минут), и только потом открывает его в Chrome (если Chrome нет — в браузере по умолчанию). Обычно 1–2 минуты.

**«Закончить занятие»:** останавливает чат, Ollama и Docker, освобождает память.

**Зелёная точка** у модели = модель сейчас в видеопамяти. При запуске ярлыком модель держится 10 минут без вопросов, при запуске Ollama из меню Пуск — 5 минут. Потом выгружается — первый ответ после паузы на 10–20 секунд дольше. Это нормально.

## 12. Как пользоваться ребёнку

1. «Начать занятие» → войти под своим логином.
2. Выбрать предмет: название модели со стрелкой ˅ вверху чата.
3. **Новый чат на каждую тему** («Новый чат» вверху слева). В старом чате модель путается и повторяется.
4. Определения и правила просить **полным названием, как в учебнике**: «дай определение **арифметического** квадратного корня из учебника», «дай правило про безударные гласные в корне».
5. Спрашивать по теме, а не по номеру страницы: «что такое трапеция», а не «что на стр. 31».
6. Упражнения: «дай упражнение из учебника на тему …» — задания из учебника проверяются надёжнее придуманных.
7. Можно прикрепить фото (скрепка / «+»).
8. Смотреть на «1 Источник» — это ответ из учебника.
9. «Закончить занятие».

Родителю: периодически просматривайте чаты ребёнка. Модель 12B иногда ошибается в разборе слов и в проверке вычислений — сверяйтесь с ответами в конце учебника.

## 13. Как менять правила репетитора

| Что поменять | Где |
|---|---|
| Правила одного предмета | Модели → предмет → ✏️ → Системный промпт → **Сохранить и обновить** |
| Общее правило | во **всех** предметах (актуальные блоки — `PROMPTY-PO-PREDMETAM.md` на GitHub) |
| Как репетитор работает с учебником | Документы → **Шаблон RAG** |
| Как ищется кусок учебника | Интерфейс → **Запрос на генерацию промпта** |

`Modelfile` при подключённом учебнике не используется — его правила продублированы в промптах. После любых изменений проверяйте в **новом** чате.

Что заложено в правилах:

| № | Правило |
|---|---|
| Главное | не давать готовый ответ; **цитата из учебника — не готовый ответ** |
| 14 | «что такое…» → наводящие вопросы → цитата для сравнения; «из учебника / дай определение» → сразу цитата; «не знаю» → цитата |
| 15 | не придумывать цитаты, авторов, страницы; нет в учебнике — «Я не нашёл это в учебнике» |
| 16 | сначала проверить ответ ребёнка («Верно!» / «Не совсем»), не повторять вопрос |
| 17 | тренировка: по одному заданию **из учебника**, проверка со словом целиком, итог через 5 заданий |
| 18 | не повторять одну цитату; на «не понимаю» — проще и на примере |
| 19 | проверять, что пример подходит под правило |
| Шаблон RAG | цитата должна содержать слово обсуждаемой темы; нет нужного фрагмента — не давать своё определение, а подсказать полное название темы |

## 14. Решение проблем

| Проблема | Что делать |
|---|---|
| Страница не открывается / «ERROR» / английский интерфейс без оформления | Подождать, **Ctrl+F5**. Запускать через ярлык — он ждёт готовности. `docker restart open-webui` |
| Интерфейс на английском | Другой браузер: имя → Settings → General → Language → Русский |
| `Model not found` у ребёнка | `tutor:latest` должен быть **включён** и с доступом ребёнку «Прочитать» (5.6) |
| Нет моделей / `Cannot connect to host.docker.internal:11434` | Ollama не запущена: ярлык или Пуск → Ollama. Если запущена — PowerShell: `[Environment]::SetEnvironmentVariable("OLLAMA_HOST", "0.0.0.0", "User")`, перезапустить Ollama |
| `does not support tools` | Расширенные параметры → **Вызов функции → По умолчанию**; Возможности → снять «Встроенные инструменты» |
| `Failed to save model` | ID модели латиницей, без пробелов и скобок |
| Нет «1 Источник» | У модели: Знания — база прикреплена; Фильтры — «Учебник в каждом вопросе»; фильтр включён в Функциях; в базе файл с текстом |
| «Цитирует» несуществующий учебник, авторов, страницы | Ответ без источника = выдумка. Проверить фильтр (раздел 7) |
| На «дай определение из учебника» цитирует **другую тему** (например, функцию) | Интерфейс: **Генерация поискового запроса — вкл**, «Запрос на генерацию промпта» — из файла, Модель локальной задачи = `gemma3:12b`; Документы: Top K = 5, новый Шаблон RAG. Просить полным названием термина |
| «В учебнике нет», хотя тема там есть | Просить полным названием, как в учебнике («арифметический квадратный корень»); Top K = 5 |
| Сразу выдаёт определение вместо наводящих вопросов | Температура `0.2`; актуальный Шаблон RAG; новый чат |
| Спрашивает «что такое определение?» вместо цитаты | Актуальный промпт предмета (правило 14) и Шаблон RAG |
| Зацикливается, повторяет вопрос, не проверяет ответы | Новый чат; в промпте правила 16–18; Шаблон RAG с «Правилом №2» |
| Кривые упражнения / неверная проверка | Просить задания **из учебника**. Это предел модели 12B |
| Подсказки «Продолжить» под ответом | Выключить генерацию продолжения: общую (5.4) **и** личную у ребёнка (9) |
| Названия чатов по-английски | Промпт для генерации заголовка (5.4) |
| Учебник грузится очень долго, процессор 100% | OCR выключить (5.2); удалить файл; `docker restart open-webui` |
| В журнале `KeyError: 'model'` | Сбой генерации названий, на ответы не влияет |
| Ответы медленные | Закрыть игры/видео; `ollama ps` — должна быть одна модель, `100% GPU` |

Журнал Open WebUI: `docker logs open-webui --tail 60`.

## 15. Обслуживание

### Перенос моделей и данных на диск D
1. «Закончить занятие»; значок ламы → **Quit Ollama**.
2. PowerShell:
   ```powershell
   [Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "D:\Ollama\models", "User")
   New-Item -ItemType Directory -Path "D:\Ollama" -Force
   Move-Item "$env:USERPROFILE\.ollama\models" "D:\Ollama\models"
   ```
3. **Ollama → Settings → Model location → `D:\Ollama\models`** (обязательно — главнее переменной). Quit Ollama → открыть снова.
4. Закрыть **все** окна терминала, открыть новое: `ollama list`.
5. **Если список пуст — не запускайте `ollama pull`**: модели начнут качаться заново на C. Проверьте п. 3, перезапустите Ollama или компьютер.
6. Docker Desktop → ⚙️ **Settings → Resources → Advanced → Disk image location** → `D:\Docker` → **Apply & restart** (аккаунты, чаты, учебники переедут вместе).
7. Когда всё работает с D: `Remove-Item "$env:USERPROFILE\.ollama\models" -Recurse -Force`.

«Двойные» строки в `ollama list` после переноса — записи на одни и те же файлы, место не занимают. Не удаляйте.

### Удаление моделей
Обычно: `ollama rm <модель>`. Не удаляйте `gemma3:12b`, `bge-m3`, `tutor`.

Ошибка **`untrusted mount point`**:
1. Обновите Ollama и попробуйте снова. Не помогло — вручную:
2. Quit Ollama + завершить процессы `ollama` в Диспетчере задач. **Команды `ollama` не вводить** — они снова запускают Ollama.
3. В **обычном** PowerShell (путь — ваша папка моделей; модель/тег — свои):
   ```powershell
   Get-ChildItem "D:\Ollama\models\manifests-v2" -Recurse -Attributes ReparsePoint | Where-Object { $_.FullName -like '*\gemma3\27b' } | ForEach-Object { $_.Delete() }
   Remove-Item "D:\Ollama\models\manifests\registry.ollama.ai\library\gemma3\27b" -Force -ErrorAction SilentlyContinue
   ```
   (`Remove-Item`/`del` на саму ссылку не работают — только `.Delete()`.)
4. Проверить, что записей не осталось:
   ```powershell
   Get-ChildItem "D:\Ollama\models" -Directory -Filter "manifests*" | ForEach-Object { Get-ChildItem $_.FullName -Recurse -Force -File } | Select-Object FullName
   ```
5. Запустить Ollama → `ollama list`. Лишние файлы Ollama удалит сама.

### Обновление
- **Open WebUI:** `docker pull ghcr.io/open-webui/open-webui:main` → `docker stop open-webui` → `docker rm open-webui` → команда `docker run` из раздела 4 (данные сохранятся). После обновления — проверка (раздел 10), названия настроек могут сдвинуться.
- **Ollama:** новый установщик поверх.
- **`tutor`** (если меняли `Modelfile`): `cd D:\Tutor` → `ollama create tutor -f Modelfile`.
- **Промпты и шаблоны:** берите свежие файлы с GitHub и вставляйте в те же поля (раздел 13).

## 16. Модель покрупнее (не используем)

`gemma3:27b` точнее в разборе слов, но на 12 ГБ видеопамяти работает наполовину на процессоре (`ollama ps` → `50%/50% CPU/GPU`) и печатает очень медленно. Нужна видеокарта на 24 ГБ. `qwen3:14b` не подходит — не понимает фото. Остаёмся на `gemma3:12b`. Если 27B скачана — удалить: `ollama rm gemma3:27b` (при ошибке — раздел 15).
