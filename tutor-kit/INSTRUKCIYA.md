# Локальный ИИ-репетитор: полная инструкция

Компьютер: HyperPC, RTX 4070 12 ГБ, 32 ГБ ОЗУ, Windows 11.
Всё работает на этом же ПК, без интернета и без отправки данных наружу (интернет нужен только для скачивания).

Что получится: ребёнок нажимает ярлык «Начать занятие», в браузере открывается чат-репетитор, который **не даёт готовых ответов, а наводит вопросами**. Закончил — нажал «Закончить занятие», и всё выключается.

> Ссылки ведут на главные страницы официальных сайтов. Интерфейсы иногда меняются, поэтому названия кнопок могут слегка отличаться.

## Шаг 0. Что нужно скачать

| Что | Зачем | Ссылка |
|---|---|---|
| Ollama | запускает ИИ-модели | https://ollama.com/download |
| Docker Desktop | запускает веб-интерфейс чата | https://www.docker.com/products/docker-desktop/ |
| Open WebUI | сам интерфейс чата (скачается через Docker) | документация: https://docs.openwebui.com |

Свободного места нужно около 25 ГБ (модели ~8 ГБ + Docker).

## Шаг 1. Установить Ollama

1. Скачайте установщик по ссылке выше и запустите его.
2. Откройте **PowerShell** (Пуск → напишите `PowerShell`).
3. Скачайте модели:

```powershell
ollama pull gemma3:12b
ollama pull bge-m3
```

- `gemma3:12b` — основная модель-репетитор (~8 ГБ). Хорошо пишет по-русски и понимает **фото** тетради и учебника.
- `bge-m3` — маленькая модель для поиска по учебникам (понимает русский).

Проверка: `ollama run gemma3:12b`, напишите «Привет». Выход: `/bye`.

> Модель целиком помещается в 12 ГБ видеопамяти, поэтому отвечает быстро.
> Дополнительно для сложной математики можно поставить `ollama pull qwen3:14b`. Но у неё включён «режим размышления», где она может показать ребёнку готовое решение. Для репетитора безопаснее `gemma3:12b`.

---

## Шаг 2. Создать модель «Репетитор»

1. Скопируйте файл `Modelfile` из этой папки (`tutor-kit`) в `C:\Tutor\`.
2. Возраст и класс (14 лет, 8 класс) уже вписаны. Если нужно изменить, откройте файл в Блокноте и поправьте строку с возрастом.
3. В PowerShell:

```powershell
cd C:\Tutor
ollama create tutor -f Modelfile
```

Появилась модель `tutor`. Именно её будет использовать ребёнок. Промпт с правилами «не давать ответ» уже внутри.

---

## Шаг 3. Установить Docker Desktop и запустить Open WebUI

1. Установите Docker Desktop по ссылке выше. Если попросит, включите WSL 2 и перезагрузите ПК.
2. Откройте Docker Desktop, дождитесь, пока он запустится.
3. В PowerShell выполните (одной строкой):

```powershell
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -e OLLAMA_BASE_URL=http://host.docker.internal:11434 -v open-webui:/app/backend/data --name open-webui ghcr.io/open-webui/open-webui:main
```

Без `--restart always`, чтобы чат сам не запускался вместе с Windows.

4. Откройте в браузере http://localhost:3000
5. **Первая регистрация становится администратором.** Зарегистрируйтесь сами (родитель): имя, почта (любая), пароль.

## Шаг 4. Настроить Open WebUI (под родителем)

> Ниже названия кнопок в русском интерфейсе, в скобках английский оригинал. Перевод в разных версиях может немного отличаться, ищите по смыслу.

### Где что находится

- **Левая боковая панель** — список чатов. Если её не видно, нажмите значок ☰ вверху слева.
- **Ваше имя / аватар внизу слева** → меню: **Настройки** (Settings, личные), **Панель администратора** (Admin Panel), **Выйти**.
- **Рабочее пространство** (Workspace) — пункт в левой панели, вверху. Там вкладки **Модели**, **Знания**, **Промпты**, **Инструменты**.
- В **Панели администратора** вверху вкладки: **Пользователи** (Users) и **Настройки** (Settings). В настройках слева меню разделов: **Общее**, **Подключения**, **Модели**, **Документы**, **Аудио** и др.

### 4.1. Проверить подключение к Ollama
Имя внизу слева → **Панель администратора** → **Настройки** → **Подключения** (Connections).
В блоке **Ollama API** должен быть адрес `http://host.docker.internal:11434` и включён переключатель. Нажмите значок 🔄 (проверить соединение), должно появиться «Соединение с сервером проверено».

### 4.2. Включить поиск по учебникам на русском
**Панель администратора → Настройки → Документы** (Documents):
- **Движок модели встраивания** (Embedding Model Engine) → выберите `Ollama`.
- **Модель встраивания** (Embedding Model) → впишите `bge-m3`.
- Внизу нажмите **Сохранить** (Save). Если спросит про переиндексацию, подтвердите.

### 4.3. Запретить саморегистрацию
**Панель администратора → Настройки → Общее** (General) → выключите **Разрешить новые регистрации** (Enable New Sign Ups) → **Сохранить**.

### 4.4. Создать аккаунт ребёнка
**Панель администратора → Пользователи** (Users) → кнопка **«+»** справа вверху → **Добавить пользователя** (Add User):
- **Роль** → `Пользователь` (User), не «Администратор»;
- **Имя**, **Email** (можно выдуманный, например `syn@home.local`), **Пароль**;
- **Сохранить**.

### 4.5. Показать ребёнку только репетиторов
1. **Панель администратора → Настройки → Модели** (Models). Здесь список всех моделей.
2. Нажмите на `gemma3:12b` (или значок карандаша ✏️ рядом) → найдите **Видимость / Доступ** (Visibility / Access) → поставьте **Частный** (Private) → **Сохранить**.
3. То же самое для `bge-m3` и любых других моделей, кроме репетиторов.
4. У модели `tutor` поставьте **Публичный** (Public) → **Сохранить**.

Проверка: выйдите (имя внизу слева → **Выйти**) и войдите под аккаунтом ребёнка. Список моделей открывается кнопкой с названием модели и стрелкой ˅ **внутри поля ввода сообщения, справа** (рядом с микрофоном), например `tutor:latest ˅`. В старых версиях эта кнопка вверху слева. В списке должны быть только репетиторы.

Под аккаунтом ребёнка в левой панели нет пункта **Рабочее пространство** — так и должно быть. Если его не видно и под вашим аккаунтом, значит вы вошли не как администратор.

### 4.6. Настроить саму модель `tutor`
**Панель администратора → Настройки → Модели** → нажмите на `tutor:latest`.

- **Системный промпт** — оставьте пустым: правила уже внутри модели (из `Modelfile`).
- **Расширенные параметры** → **Показать** → **Вызов функции**: нажмите на «Нативный», чтобы стало **По умолчанию**. Иначе будет ошибка `does not support tools`.
- **Возможности** — оставьте галочки только у: **Видение** (фото тетради), **Загрузка файла**, **Контекст файла**, **Цитаты**, **Обновления статуса**. Снимите: **Поисковая система**, **Терминал**, **Генерация изображений**, **Интерпретатор кода**, **Воспоминания**, **Встроенные инструменты**.
- **Функции по умолчанию** — все выключены.
- **Встроенные инструменты** — если после сохранения ошибка про tools останется, снимите здесь все галочки.
- **Предложения промптов по умолчанию** — можно добавить школьные подсказки через «+», например: Заголовок «Помоги с задачей», Подзаголовок «я не знаю, с чего начать», Содержание «Помоги мне разобраться с задачей: ».
- Внизу **Сохранить и обновить**.

Те же галочки снимайте у каждого предметного репетитора из шага 8.

## Шаг 5. Загрузить учебники

### Где взять
- Электронные формы учебников (ЭФУ): издательство «Просвещение» (https://lecta.ru), «Российский учебник» (https://rosuchebnik.ru), «Учебники» ЭФУ (https://uchebnik.mos.ru для московских школ).
- Бесплатные уроки по ФГОС: Российская электронная школа https://resh.edu.ru
- У школьной библиотеки или классного руководителя можно спросить официальные электронные версии.
- Отсканируйте или сфотографируйте свой бумажный учебник и соберите в PDF (потребуется распознавание текста, см. ниже).

> Загружайте только материалы, которые вы вправе использовать для личных целей (ваши учебники, школьные ЭФУ, свободные материалы).

### Что подойдёт
- **PDF с текстом** (можно выделить мышкой текст) — идеально.
- **Сканы-картинки в PDF** — нужно сначала распознать текст (OCR), например в Adobe Acrobat, ABBYY FineReader или бесплатно через https://www.ocr2edit.com. Без текста модель их не прочитает.
- Файлы лучше делить по предметам и классам, один учебник на файл.

### Как загрузить
1. Под родителем: левая панель → **Рабочее пространство** (Workspace) → вкладка **Знания** (Knowledge) → кнопка **«+»** или **Создать знание**.
2. **Название**: например `Алгебра 8 класс`, **Описание**: любое. Нажмите **Создать знание**. Отдельная база на каждый предмет.
3. Внутри базы нажмите **«+»** → **Загрузить файлы** (Upload files) и выберите PDF. Дождитесь, пока обработка закончится (значок загрузки у файла пропадёт).
4. Повторите для других предметов.
5. Подключите базу к репетитору: **Рабочее пространство → Модели** → нажмите на нужную модель (✏️ **Редактировать**) → раздел **Знания** → **Выбрать знания** (Select Knowledge) → отметьте базу → внизу **Сохранить и обновить** (Save & Update).

Если модель `tutor` не видна во вкладке **Рабочее пространство → Модели**, создайте предметные модели по шагу 8 и подключайте знания к ним.

Чтобы репетитор строже держался учебника, добавьте в его **Системный промпт** строку:
«Опирайся на материалы учебника из базы знаний, используй те же термины, что в учебнике».

## Шаг 6. Ярлыки «Начать» и «Закончить»

1. Создайте папку `C:\Tutor\`.
2. Скопируйте туда `Start-Tutor.bat` и `Stop-Tutor.bat` из этой папки.
3. Правой кнопкой по каждому → **Отправить → Рабочий стол (создать ярлык)**. Переименуйте ярлыки в «Начать занятие» и «Закончить занятие».
4. Отключите автозапуск:
   - Диспетчер задач → **Автозагрузка** → отключите **Ollama**.
   - Docker Desktop → **Settings → General** → снимите «Start Docker Desktop when you sign in».

Как работает:
- **Начать** → запускает Ollama и Docker, включает чат и открывает браузер (занимает ~1 минуту).
- Если ребёнок забыл выключить, модель сама выгрузится из видеокарты через 10 минут без запросов.
- **Закончить** → останавливает чат, Ollama и Docker, освобождает память.

В адресной строке браузера заходить нужно на http://localhost:3000 (скрипт откроет сам).

## Шаг 7. Как пользоваться ребёнку

1. Нажать «Начать занятие», подождать, пока откроется чат.
2. Войти под своим логином.
3. Выбрать предмет: кнопка с названием модели и стрелкой ˅ в поле ввода сообщения, справа.
4. Написать задание или прикрепить **фото** страницы (значок скрепки).
5. Репетитор будет задавать наводящие вопросы. Отвечать нужно по шагам.
6. Закончил → «Закончить занятие».

Можно включить голосовой ввод: имя внизу слева → **Настройки** → **Аудио** (микрофон должен быть разрешён в браузере). В чате появится значок микрофона 🎤.

## Шаг 8. Репетиторы по предметам (8 класс)

Готовые промпты для всех 12 предметов (алгебра, геометрия, вероятность и статистика, информатика, физика, химия, биология, русский язык, литература, история, английский, география) лежат в файле `PROMPTY-PO-PREDMETAM.md`.

Для каждого предмета:
1. Левая панель → **Рабочее пространство** → **Модели** → кнопка **«+»** (Новая модель).
2. **Имя модели**: название предмета, например `Алгебра`.
3. **Базовая модель** (Base Model) → выберите `tutor`.
4. **Системный промпт** (System Prompt) → вставьте **весь** блок этого предмета из файла. Он уже включает общие правила «не давай ответ»: промпт в Open WebUI заменяет промпт из `Modelfile`, а не дополняет его.
5. **Знания** → **Выбрать знания** → отметьте учебник по этому предмету (шаг 5).
6. **Вызов функции** и **Возможности** — как в пункте 4.6.
7. **Видимость / Доступ** → **Публичный**, чтобы ребёнок видел модель.
8. Внизу **Сохранить и обновить**.

Ребёнок выбирает нужный предмет в списке моделей.

## Решение проблем

| Проблема | Что делать |
|---|---|
| Страница http://localhost:3000 не открывается | Подождите ещё минуту: Docker запускается долго. Проверьте, что в Docker Desktop контейнер `open-webui` запущен |
| В списке нет моделей | Убедитесь, что запущен Ollama (`ollama list` в PowerShell). Проверьте, что при создании контейнера был параметр `OLLAMA_BASE_URL` |
| Ошибка `tutor:latest does not support tools` | Gemma 3 не умеет «инструменты». Под администратором: **Панель администратора → Настройки → Модели** → нажмите на `tutor` → **Расширенные параметры** (Advanced Params) → **Вызов функций** (Function Calling) → `По умолчанию` (Default) вместо `Нативный` (Native) → **Сохранить**. Также в поле ввода чата выключите всё под значком ◇ / «+» (веб-поиск, интерпретатор кода, инструменты) |
| Репетитор слишком быстро даёт ответ | Допишите в промпт строгие фразы вроде «Если ребёнок просит ответ, откажись три раза подряд, дай только подсказку». Протестируйте сами |
| Ответы медленные | Закройте игры и тяжёлые программы, они занимают видеопамять. Попробуйте `ollama pull qwen2.5:7b` и создайте на ней второго репетитора |
| Не находит в учебнике | Проверьте, что в PDF есть текст (а не только картинки), и что учебник подключён к модели `tutor` |
| Модель ошибается в задаче | Это возможно у любых локальных моделей. Для сложных заданий сверяйтесь с учебником и периодически просматривайте историю чатов под родителем |

## Обновление

- Модель: `ollama pull gemma3:12b`, затем снова `ollama create tutor -f Modelfile`.
- Open WebUI: `docker pull ghcr.io/open-webui/open-webui:main`, затем остановить, удалить и создать контейнер той же командой из шага 3 (данные сохранятся в томе `open-webui`):
  `docker stop open-webui` → `docker rm open-webui` → команда из шага 3.

## Вариант без Docker (если Docker не может скачать Open WebUI)

Если `docker run` выдаёт ошибку `failed to resolve reference "ghcr.io/open-webui/..."` или `connection attempt failed`, значит Docker не может достучаться до сервера ghcr.io. Тогда Open WebUI можно поставить через Python, Docker не нужен вообще.

1. Скачайте **Python 3.11** (именно 3.11, с новыми версиями Open WebUI может не работать): https://www.python.org/downloads/release/python-3119/ → «Windows installer (64-bit)».
2. При установке **обязательно поставьте галочку «Add python.exe to PATH»**.
3. Откройте новое окно PowerShell и выполните:
   ```
   py -3.11 -m pip install open-webui
   ```
   Скачивается несколько гигабайт, это займёт 10–30 минут.
4. Первый запуск для проверки:
   ```
   open-webui serve --port 3000
   ```
   Подождите, пока появится надпись про запуск, и откройте http://localhost:3000. Дальше всё как в шаге 3.5 и шаге 4.
5. Для ярлыков используйте `Start-Tutor-Python.bat` и `Stop-Tutor-Python.bat` вместо обычных. Docker Desktop можно удалить.

Обновление Open WebUI в этом варианте: `py -3.11 -m pip install -U open-webui`.

## Перенос всего на диск D

На диске C у вас SSD 512 ГБ, на D — 2 ТБ. Больше всего места занимают **модели Ollama** (~10 ГБ) и **данные Docker** (образ Open WebUI ~4 ГБ, аккаунты, чаты, учебники). Их и переносим. Сами программы весят немного, их можно оставить на C.

> Если большой диск у вас называется не `D:`, замените букву везде ниже.

### 0. Всё остановить
Нажмите ярлык «Закончить занятие» (или `Stop-Tutor.bat`). Значка ламы Ollama в трее у часов быть не должно. Если есть — правой кнопкой → **Quit Ollama**.

### 1. Модели Ollama
Откройте PowerShell и выполните по очереди:

```powershell
[Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "D:\Ollama\models", "User")
New-Item -ItemType Directory -Path "D:\Ollama" -Force
Move-Item "$env:USERPROFILE\.ollama\models" "D:\Ollama\models"
```

- Первая строка говорит Ollama, что модели теперь лежат на D.
- Последняя переносит папку (несколько минут, курсор может «висеть» — это нормально).

**Закройте PowerShell**, откройте новый и проверьте:
```powershell
ollama list
```
Должны быть `tutor`, `gemma3:12b`, `bge-m3`. Если список пустой — перезагрузите компьютер и проверьте ещё раз.

### 2. Данные Docker (Open WebUI, аккаунты, чаты, учебники)
1. Откройте **Docker Desktop** (дождитесь «Engine running» внизу слева).
2. Значок шестерёнки ⚙️ вверху справа → **Settings** → **Resources** → **Advanced**.
3. **Disk image location** → **Browse** → создайте и выберите папку `D:\Docker`.
4. Нажмите **Apply & restart**. Docker перенесёт свой диск на D — это займёт несколько минут, не закрывайте окно.

Аккаунты, чаты, настройки и учебники лежат внутри этого диска, поэтому переносятся вместе с ним. Ничего заново настраивать не нужно.

Проверка: в PowerShell `docker start open-webui`, через минуту откройте http://localhost:3000 и войдите под своим аккаунтом.

### 3. Папка со скриптами
1. Перенесите папку `C:\Tutor` в `D:\Tutor` (вырезать → вставить).
2. Удалите старые ярлыки с рабочего стола и создайте новые из `D:\Tutor` (правой кнопкой по `.bat` → **Отправить → Рабочий стол (создать ярлык)**).

Если меняете `Modelfile`, команда пересоздания теперь такая:
```powershell
cd D:\Tutor
```

### 4. (Необязательно) Сами программы на D
Программы занимают 2–4 ГБ. Если хотите и их на D:
- **Ollama**: удалите через «Параметры → Приложения», скачайте `OllamaSetup.exe` и запустите из PowerShell в папке загрузок: `.\OllamaSetup.exe /DIR="D:\Programs\Ollama"`. Модели не пропадут — они уже на D.
- **Docker Desktop**: переносить не рекомендую. Его переустановка сложнее, а основное место (данные) уже на D.

### Сколько места освободится на C
Примерно 15–20 ГБ. Проверить: Проводник → «Этот компьютер».
